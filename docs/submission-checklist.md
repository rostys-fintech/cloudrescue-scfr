- [ ] Test Light theme.
- [ ] Test Dark theme.
- [ ] Run the full guided demo from Scene 1 to Scene 6.
- [ ] Confirm narration finishes before each scene changes.
- [ ] Confirm subtitles match the current scene.
- [ ] Confirm Focus View enters and exits correctly.
- [ ] Confirm keyboard Left / Right navigation works.
- [ ] Confirm the outage provider is correct in Blue, Orange and Green scenario replays.
